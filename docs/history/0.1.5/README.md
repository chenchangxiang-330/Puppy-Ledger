# 小狗账本 0.1.5

中文离线 Android 记账应用。本次基于已交付的 0.1.4+5 修正开屏角色，版本 **0.1.5+6**。

## 本轮修正

删除开屏中重新描绘的小狗轮廓，直接复用已有的 `assets/illustrations/puppy_sage.png` 双小狗依偎图片。脸型、耳朵、表情与首页草地绿主题完全同源；三个主题的原始 PNG 和用户指定的沙发读书图标均未改动。

约 1.3 秒的开屏采用整张原图轻摇、轻微上下移动，并依次显示「嗨～」「你好呀」问好气泡；不单独重画或转动爪子。支持跳过，系统减少动态效果时直接进入首页；页面和主题切换、从后台返回均不重播。

其余生产 Dart 文件与 0.1.4 逐字节相同：保留悬浮「记一笔」、已移除的相册入口、点击与主题切换闪屏修正，以及记账、分类、退款、编辑、删除撤销、统计、完整备份恢复、三主题与本地 SQLite 存储。

## 安装

APK 是实际构建的 **Release AOT / arm64 / Android 7.0+**。包名仍为 `com.example.puppy_ledger.linepuppy`，与 0.1.4 使用同一签名，版本号从 5 增至 6。

直接覆盖安装上一版线条版，**不要先卸载**，保留现有账本和主题设置。数据库 schema 1、备份格式 v1 及数据路径不变。更早的 0.1.0 包名不同，迁入需使用应用内完整备份恢复。

源码不含私钥；其他开发机使用不同签名重新构建的 APK 无法覆盖本交付包。源码 ZIP 和交付总包不是应用内账本备份。

## 验证与演示

静态分析无问题，60 项自动化测试通过，包含真实保存/失败回滚、数据库重开、编辑删除撤销、主题持久化、备份恢复、连续点击和局部画面变化、主题切换布局稳定、小屏及大字号适配。

开屏专项检查覆盖原图引用、动画中图片元素保持不变、轻摇推进、一次播放、跳过、后台终止、减少动画和 320×568 / 2 倍字号。另对生成的视频开屏关键帧作人工视觉核对。

附带演示视频由真实 Flutter UI、自动化手势和临时 SQLite 逐帧渲染，展示修正后的开屏及原有点击、悬浮滚动、记账、撤销和主题切换。**不是安卓真机录屏**。当前无连接的安卓设备，尚未验证手机上的安装升级、GPU 闪屏、触感、系统开屏过渡或实机帧率。

## 构建

Flutter 3.47.9 / Dart 3.13.7 / JDK 21 / Android SDK 36。无新增依赖，依赖锁文件与上一版一致。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --flavor linepuppy --target-platform android-arm64
```

- `lib/ui/startup_welcome.dart`：原图小狗开屏、轻摇和气泡。
- `test/startup_test.dart`：开屏外观来源与生命周期回归验证。
- `tool/motion_recording_test.dart`：真实 Flutter UI 交互录像复现。
- `docs/VALIDATION.md`：验证范围和限制；`docs/history/`：历史版本记录。

测试示例账目只存在于临时数据库；APK 首次安装为空账本。
