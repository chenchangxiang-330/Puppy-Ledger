## 闪屏修复依据与限制

源码中主题选择原本共用全局“正在处理”流程，在 SQLite 写入前后插入/移除一块进度区，同时禁用所有设置控件，造成页面位置短暂跳动。现改为主题专用的提交保护，不再插入该占位。额外加入三图预加载、无空白图片替换、小狗独立 RepaintBoundary 和稳定主题对象。

已验证软件渲染中的点击范围、主题切换和页面结构稳定。用户描述的所有真机闪屏原因没有可用设备复现；不能将自动化通过等同于已验证该手机 GPU/系统渲染正常。没有擅自切换渲染后端或关闭所有动画。

## 视频与实机范围

演示录像来自真实 Flutter UI 与临时 SQLite，由自动化手势驱动并逐帧捕获，含触点和操作字幕。不是手机/模拟器系统录屏，也不是性能帧率测试。所有示例数据仅用于临时数据库，未放进 APK。

当前无连接的安卓设备，未进行真机覆盖安装、桌面图标蒙版、冷启动系统过渡、触感、文件选择器或实机性能验证。安装兼容性依据实际编译、包名/版本/签名及 ZIP 校验，详细参数见 TOOLCHAIN.md。
