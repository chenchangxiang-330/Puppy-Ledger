# 小狗账本 0.1.4

中文离线 Android 记账应用，基于已交付的 0.1.3+4 源码继续修改，当前 **0.1.4+5**。

## 本轮更新

1. 删除「从相册换一张」「恢复默认小狗」及图片保存提示。保留三套主题和原有账本管理。旧备份里的图片仍可兼容，不主动删除旧图片或账目。
2. 「记一笔」恢复为右下角悬浮按钮，去掉遮挡列表的整条底色。按钮周围显示下方内容并可滑动；列表底部留空，末条账目可以滚到按钮上方。
3. 冷启动增加约 1.3 秒双小狗挥爪问好：两只小狗分别挥动外侧小爪，轻轻出现，随后进入首页。支持跳过；切换页面、主题及后台返回不重播；系统减少动画时直接进入首页。
4. 桌面名称改为「小狗账本」。图标使用用户上传的双小狗躺在沙发上读书的图片，原图完整保留，仅按 Android 图标规格缩放和适配圆形/圆角蒙版。
5. 针对小狗点击/切换闪屏反馈：去除主题保存时造成页面上下跳动的全局进度区；提前解码三主题图片，保留旧图直到切换；给小狗动效独立绘制区域，复用主题配置，避免无关数据刷新触发整页主题过渡。

保留记账、退款、分类、历史日期、日周月统计、完整 ZIP 备份恢复和本地 SQLite。三张主题小狗素材保持原样。0.1.3 的按压、520ms 小狗互动、1.5 秒气泡、保存庆祝、左滑编辑/删除及 5 秒撤销继续可用。

## 安装

本版 APK 为 **Release AOT，arm64，Android 7.0+**。包名仍为 com.example.puppy_ledger.linepuppy，沿用 0.1.3 签名、数据库及数据目录，版本号由 4 提升至 5。

可直接覆盖安装上一版线条版，**不要先卸载**。名称变化不代表新建了另一个应用。源码不含签名私钥；其他开发机使用新签名自行构建的包不能直接覆盖本次 APK。

更早的 0.1.0 原版包名不同，如需迁入请使用 App 内「导出完整备份 → 从备份恢复」。交付总包和源码 ZIP 不能当作账本备份导入。

## 验证与演示

静态分析无问题，60 项自动化测试通过，包含原有 54 项和新增开屏/闪屏/悬浮交互测试。新增检查包括：

- 开屏只播放一次、跳过、后台终止、减少动画、320×568 / 2 倍字号。
- 三主题点击小狗前后逐像素比较：小狗与气泡区域之外没有画面变化。
- 反复切换主题，主题卡片位置不变，不出现全局进度条、空白白帧或重新开屏。
- 从悬浮按钮旁边拖动仍可滚动列表；相册相关入口已消失。

附带短演示视频，展示开屏、悬浮滑动、小狗互动、保存、撤销和主题切换。视频使用真实 Flutter 组件和临时 SQLite 自动化逐帧渲染，**不是 Android 真机录屏**。环境没有连接的安卓设备，未对用户手机 GPU、触感、安装升级或实机帧率作验证。软件渲染测试未出现整屏闪白，不能据此承诺所有手机上的闪屏均已消失。

## 构建

Flutter 3.47.9 / Dart 3.13.7 / JDK 21 / SDK 36。无新增运行依赖，pubspec.lock 与上一版一致。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --flavor linepuppy --target-platform android-arm64
```

- lib/ui/startup_welcome.dart：一次性开屏与原生矢量挥爪动画。
- lib/ui/motion.dart：小狗互动、按压反馈和共用参数。
- lib/ui/settings_page.dart：简化设置与无布局跳动的主题切换。
- assets/branding/launcher_original.png：用户上传的图标原图。
- tool/generate_icon.py：从原图生成 Android 多密度和自适应图标，需 Pillow。
- tool/motion_recording_test.dart：可复现的自动化交互录像。
- docs/VALIDATION.md：验证范围与限制；docs/history/ 保留旧版本说明。

金额按整数分保存；数据库 schema 1 和备份格式 v1 均不变。测试使用临时数据，交付 App 首次安装为空账本。
