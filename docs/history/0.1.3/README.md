# 小狗账本 · 线条版 0.1.3

中文、离线、Android Flutter 记账应用，版本 **0.1.3+4**。从当前已交付的 0.1.2+3 完整源码继续修改，保留支出/退款、分类、历史补记、日周月统计、自选图片、完整 ZIP 备份恢复和本地 SQLite 存储。首次安装为空账本。

## 本次功能

| 主题 | 沿用素材 | 点击小狗 |
| --- | --- | --- |
| 奶油黄 | 一起记账 | 轻弹跳，「今天也要好好记账呀」 |
| 蜜桃粉 | 双小狗贴贴 | 轻摇晃、3 颗粉色爱心，「贴贴，快乐记一笔」 |
| 草地绿 | 双小狗依偎 | 小蹦跳、3 颗星星，「又是元气满满的一天」 |

- 小狗动作 520ms；气泡 1.5 秒后消失；连续点击限频 700ms，不累积粒子、计时器或气泡。图片原样内置，仅在代码中移动、缩放、旋转。
- 主要操作按钮、分类、主题卡片轻压至 0.96 倍，180ms 回弹；分类选中背景及边框平滑过渡。只有实际保存成功提供一次轻触感，不为普通点击添加振动。
- 保存成功返回首页并选中该笔账目的日期；新账目 280ms 淡入上移，小狗庆祝并显示「记好啦！」。金额、明细和统计同步更新。保存失败留在表单、保留输入；按钮和控制器双重防止重复提交。
- 三套主题颜色约 300ms 过渡，小狗原位交叉淡入与微缩放。主题及原有自选图片机制持久化；选择内置主题时恢复其对应素材。
- 明细左滑露出编辑/删除，同一时间只展开一条。长按也可展开，辅助功能提供编辑/删除操作。删除后底部提供 5 秒撤销；还原原 ID、金额、类型、分类、备注、日期及两个时间戳。连续删除时撤销所有尚在各自 5 秒窗口内的账目，原子写入；过期账目不恢复。离开应用后超过期限或重启后不再提供撤销。
- 月份标题区域可左右滑动；日期按钮仍保留。首页与统计共用所选日期；月底和跨年按有效日期调整。横向手势限于账目和日期标题，正常上下滚动不会触发删除。
- 「记一笔」放在列表下方独立操作区，不覆盖账目金额或滑动按钮。气泡使用固定预留区，不压住金额。页面离开/后台停止小狗效果；系统减少动态效果时保留文字反馈，关闭位移、粒子和过渡。

## 覆盖升级与安装

本版继续使用包名 **com.example.puppy_ledger.linepuppy**、数据库 schema 1 和已有签名。版本提升至 0.1.3 / 4，可覆盖本工作区交付的 0.1.1、0.1.2 线条版，保留本地账目和主题；**不需要卸载**。

APK 面向 **arm64 Android 7.0+**。下载到手机后直接打开安装，按系统提示允许该文件来源安装应用。

更早的 0.1.0 原版使用另一个包名，不能直接读取其数据库。若仍在使用原版，请先从原版「我的 → 导出完整备份」，再到线条版「我的 → 从备份恢复」导入。请勿把源码 ZIP 或交付总包当成账本备份。

## 验证与演示

静态分析、54 项自动化测试、真实 Flutter 帧录制均通过。测试覆盖真实 SQLite 保存、编辑、删除/撤销、事务失败、重开数据库、备份恢复、主题持久化、手势和连点，以及 360px/1.5 倍和 320px/2 倍字体布局。详细依据见 docs/VALIDATION.md。

随附约 22 秒 MP4，展示三主题点击、按压、保存庆祝、左滑删除/撤销和月份滑动。它由 tool/motion_recording_test.dart 驱动真实 Flutter 组件和临时 SQLite 并逐帧录制，含触点及说明字幕；**不是 Android 真机或模拟器录屏**。当前无连接的安卓设备，未进行手机安装、性能帧率、触感及 Android 系统文件选择器的实机验证。所有测试数据均独立、临时，不写入交付 App。

## 开发与结构

工具链：Flutter 3.47.9 / Dart 3.13.7 / JDK 21 / Android SDK 36；原 pubspec.lock 保持不变，未新增运行依赖。构建详情见 docs/TOOLCHAIN.md。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --flavor linepuppy --target-platform android-arm64
```

- lib/core/：金额、SQLite、备份、设置；新增原子撤销，无数据库或备份格式变更。
- lib/ui/motion.dart：统一时间参数、按压、新账目淡入、小狗互动与月份手势。
- lib/ui/swipe_entry.dart：单行左滑、互斥展开、辅助功能操作。
- assets/illustrations/：三套现有素材，字节与 0.1.2 一致，离线可用。
- test/：业务、数据库、备份、控件和交互回归测试。
- tool/：图标、界面预览和交互录制工具。
- docs/history/：保留 0.1.0、0.1.1、0.1.2 历史说明。

源码不含 SDK、缓存、用户数据库或签名私钥。原工程的 release 配置使用已有 debug signing config；本次复用其同一签名。新电脑自行构建会使用本机签名，若希望覆盖已安装的本次 APK，需另行配置相同签名。
