# 小狗账本 0.1.6

在核实的最新交付版 0.1.5+6 上开发，当前版本 **0.1.6+7**。中文、离线、本地 SQLite 存储，应用名称和包名保持不变。

## 收入与双小狗分工

- 记账页改为「支出 / 收入」。支出保留原分类，收入默认「工资、退款、兼职」，分别支持新增、改名和停用。编辑历史账目时允许保留已停用的原分类。
- 切换类型清空分类选择并更新金额、日期及角色提示；金额、日期和备注保留。新记账默认支出，编辑显示原记录真实类型。
- 首页突出整月结余，下方并列收入、支出卡片；每张卡片显示负责的小狗。保留日期、月份切换、每日明细、左滑编辑/删除和 5 秒撤销。
- 明细「全部 / 支出 / 收入」只筛选当天列表。顶部总额始终统计所选整月，日汇总单独标注。
- 默认小鸡毛管收入、小白管支出。在「我的 → 账本管理 → 小狗分工」交换后立即保存，首页、表单和成功反馈同步更新；历史账目不变。
- 成功写入后先更新金额与列表，再显示负责的小狗及提示：收入「又攒下一点小幸福！」，支出「这笔花销记好啦！」。保存失败保留表单，连续点击防止重复提交。
- 统计页统一为收入、支出、结余，分类切换「支出去向 / 收入构成」，趋势为每日结余；图表和列表采用相同日、周、月范围。
- 三主题图片原样保留。角色头像直接显示原图局部视口，没有重画脸型或耳朵；主题与分工独立。主题区更名为「今天的小狗心情」。
- 开屏、轻量互动、减少动态效果、悬浮按钮及先前闪屏修复继续保留。统计页隐藏悬浮记账按钮，避免挡住分类切换；首页与「我的」仍可快速记账。

收入包括退款，支出不再被退款冲减。**结余 = 收入 − 支出**，仅表示所选周期的收支差额。例如支出 100 元、退款到账 100 元，显示收入 100、支出 100、结余 0。

## 数据兼容

数据库 schema 从 1 升至 2，仍使用原 `puppy_ledger.db`。升级在单个 SQLite 事务内完成：支出保留，原退款转换成「收入—退款」；原 ID、金额、日期、备注、创建及更新时间均保留。另存 `legacyCategoryId` / `legacyCategoryName`，在编辑页查看原分类，备份亦保留。旧分类保留，收入默认分类 ID 遇到旧 ID 冲突时另选 ID。

升级失败回滚到旧结构和旧数据，重启可重试；成功后按数据库版本跳过迁移，不重复记账。ZIP 备份升级为 v2，包含分类类型、分工和历史分类字段；仍接受 v1 备份，并使用与数据库升级相同的转换逻辑。恢复是完整覆盖事务，多次恢复同一备份不会累加记录。旧版应用不能读取新版数据库或 v2 备份。

## 安装

交付 APK 是实际 Release AOT 构建，**arm64 / Android 7.0+**。应用 ID：`com.example.puppy_ledger.linepuppy`；版本 0.1.6 / 7。沿用可用签名配置，最终证书核验见 `docs/TOOLCHAIN.md`。

覆盖安装 0.1.5，**不要先卸载**。旧账本会自动升级；重要账目可先通过应用导出完整备份。源码 ZIP、项目总包不能作为账本备份导入。

源码不包含签名私钥。其他开发机使用不同密钥重建的 APK 不能覆盖本次签名包。更早的 0.1.0 使用不同包名，需通过应用内备份迁入。

## 验证与演示

68 项自动化回归测试覆盖收支、分工、数据兼容、失败回滚、撤销和小屏大字号等场景；详细范围见 `docs/VALIDATION.md`。交互视频展示真实 Flutter 组件、手势与临时 SQLite 数据，包括收入、首页汇总、交换分工、统计和三主题。

**视频为 Flutter 自动化逐帧演示，不是 Android 真机录屏。** 当前没有连接的安卓设备，未实测手机安装升级、系统键盘/文件选择器、触感或 GPU 性能。软件渲染无闪屏不等于所有手机均已实测。

## 复现

Flutter 3.47.9 / Dart 3.13.7 / JDK 21 / SDK 36，无新增依赖。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --flavor linepuppy --target-platform android-arm64
```

- `lib/core/migration.dart`：旧账本与 v1 备份共用迁移。
- `lib/core/store.dart`：schema 2、事务和收支分类约束。
- `lib/ui/widgets.dart`：原图角色头像视口。
- `lib/ui/app.dart`、`entry_page.dart`、`stats_page.dart`、`settings_page.dart`：收支与分工 UI。
- `test/income_migration_test.dart`、`income_ui_test.dart`：本轮回归测试。
- `tool/motion_recording_test.dart`：自动化视频复现。

测试全部使用临时数据库；首次安装仍是空账本。旧版本说明保存在 `docs/history/`。
