# 小狗账本 0.1.8

基于已交付的 0.1.7，调整首页「每日明细」和统计页「每日收支」。两张截图由 Flutter 实际渲染同一份临时 SQLite 账本取得，首次安装使用空账本。

- 每日明细标题右侧的日期按钮打开月历，可跨月选日、回到今天。收起状态也可在标题区域滑动切月。当天收入和支出显示在流水卡片首行；「全部」菜单只筛选流水。左滑编辑、删除和撤销沿用已有流程。
- 每日收支默认显示支出，也可切到包括退款在内的收入。柱形从底部零线向上绘制，点选日期可查看金额。历史长月份可左右滑动图表。当前周期显示至今天，若已记或主动选中更晚的日期，会包含至该日；历史月份使用完整自然月。卡片累计与各柱金额使用同一组记录。
- 三套主题继续控制页面配色，抱金币头像和双小狗分工沿用 0.1.7。数据库 schema 2、备份 v2 和旧备份导入规则继续使用原实现。

## 安装

这是 arm64、Android 7.0+ 的 Release APK。包名 `com.example.puppy_ledger.linepuppy`，版本 `0.1.8+9`。包名和证书与已交付的 0.1.7 一致，可直接覆盖安装并保留本地数据。0.1.6 使用其他证书，若仍在用 0.1.6，请先在旧版「我的」导出完整备份，确认 ZIP 已保存，再卸载旧版、安装新版并从备份恢复。

## 复现

```sh
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter build apk --release --flavor linepuppy --target-platform android-arm64
```

工具链与签名见 `docs/TOOLCHAIN.md`。图一、图二的数据验证和截图复现见 `docs/VALIDATION.md`。
