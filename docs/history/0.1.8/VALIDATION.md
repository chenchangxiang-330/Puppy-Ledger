# 0.1.8 验证

静态分析无问题。全套 74 项 Flutter 测试通过。截图单独使用 `tool/daily_preview_test.dart` 捕获实际组件，全程使用临时 SQLite。

| 情形 | 实测结果 |
| --- | --- |
| 同日支出 28 + 6，退款收入 100 | 首页收入 ¥100.00、支出 ¥34.00；筛到仅收入或仅支出时，当日及整月合计不变 |
| 点选 11 月 6 日 | 支出图显示 ¥34.00，切到收入显示 ¥100.00。样例 1 至 6 日的累计支出为 ¥174.00 |
| 无记录的 3 日 | 保留日期和选择位置，柱子留空；点选显示 ¥0.00 |
| 比例和方向 | 同一支出模式下，5 日与 6 日柱顶高度比例为 56:34，底部对齐。切换收入后零线仍在底部 |
| 日期与范围 | 点日期打开月历，跨月至 10 月 31 日，月汇总及流水同步更新；点击回到今天恢复 11 月 6 日 |
| 空周期、完整历史月、本期未来账目 | 空周期显示简洁提示；10 月保留 31 个位置；本月已记的未来日期计入统计 |
| 小屏和大字号 | 320 × 640、2 倍字号下检查日期按钮、筛选、最大金额、月历和图表，没有 Flutter 布局异常 |
| 交互回归 | 左滑编辑、删除撤销、切换月份、保存、主题、角色、数据库迁移、备份及闪屏回归继续通过 |

图一使用蜜桃粉，图二使用草地绿，日期和金额均来自测试账本。`test/support/daily_sample.dart` 提供示例数据。设置 `TASK_ROOT`、`CJK_FONT`、`PREVIEW_DIR` 后运行 `flutter test --no-pub tool/daily_preview_test.dart` 可复现截图。

本次没有连接 Android 真机。手机安装、真机覆盖升级及设备帧率未实测。覆盖兼容性根据新旧 APK 的包名、版本号和签名证书验证。
